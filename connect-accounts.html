Connect Broker, Exchange & Sekuritas

Satu tempat untuk mengatur koneksi akun dari PC dan memantau statusnya melalui HP.

REAL ACCOUNT SAFETY: Halaman ini adalah pusat konfigurasi/UI, bukan koneksi live yang sudah aktif. Jangan masukkan password, OTP, API secret, atau kredensial broker ke halaman statis ini. Koneksi nyata harus dibuat melalui backend aman dan diuji dengan izin baca-data terlebih dahulu.

Forex & CFD

MT5 bridge dari terminal resmi di PC.

BACKEND REQUIRED
  • HFM — MetaTrader 5
  • Broker MT5 lain — konfigurasi server per broker
  • OANDA — hanya metode/platform yang didukung jenis akun

Status live akan muncul hanya setelah backend memverifikasi koneksi dan identitas akun secara aman.

Saham Indonesia

Gunakan API resmi atau integrasi yang diizinkan oleh penyedia.

API AVAILABILITY CHECK
  • Stockbit Sekuritas
  • IPOT / Indo Premier
  • Ajaib Sekuritas
  • Mirae Asset Sekuritas

Jika API trading resmi tidak tersedia untuk akun, opsi alternatifnya adalah impor laporan atau koneksi read-only yang disetujui penyedia.

Daftarkan konektor

Form ini hanya menyimpan daftar konektor lokal di browser ini. Ini tidak login ke broker dan tidak mengirim data ke server.

Security baseline: secrets stay server-side; HTTPS; least-privilege API keys; no withdrawal permission; audit logs; manual approval before any order. Static GitHub Pages cannot run the Python MT5 bridge; PC or compatible server is required.
